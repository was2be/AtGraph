# @Graph

**@Graph is a native macOS application for intuitive data visualization, analysis, and statistics for scientific research.**

[Visit the official @Graph website](https://atgraph.app/)

## Features

* Import multiple scientific data formats
* Display data in a variety of graph and chart styles
* Perform data analysis and measurements
* Conduct statistical analysis of experimental data
* Analyze fluorescence microscopy time-series data
* Create volcano plots, heatmaps, and Venn diagrams for omics data
* Export graphs, charts, and processed data
* Use AI assistants to work with data in plain English
* Native macOS application built with SwiftUI
