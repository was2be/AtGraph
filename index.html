Overview

@Graph is a macOS application for data visualization, analysis, and statistics. It is designed for scientific research, including electrophysiology, fluorescence microscopy, genomics, and other experimental data.

Features

High-performance plotting

Render large datasets smoothly with interactive graphs and charts.

Fluorescence microscopy analysis

Open z-series and time-series images, plot ROI values, and quantify changes in fluorescence in one application.

First-class "omics" visualization

Volcano plots, heatmaps, dot plots, UpSet, Venn diagrams and many others.

Scientific file support

Import a wide variety of research data formats, including for neurophysiology, imaging, and genomics data sets.

Analysis tools

Process, measure, and extract meaning from experimental data.

Statistics tools

@Graph automatically identifies and applies appropriate statistical tests to help you better undersand your data.

AI Assistant

Choose among several AI assistants and work with your data using plain English.

Export Beautiful Charts and Graphs

Easily export your data to a variety of image formats, including vector-based SVG.

Native for macOS

Built for Apple Silicon for an intuitive and modern MacOS experience.

Privacy

Read the @Graph Privacy Policy

@Graph does not collect, transmit, or store personal information.

@Graph allows users to choose to use third-party artificial intelligence services, including those from Anthropic, Google, OpenAI, and xAI, to enhance the functionality of @Graph. When a user chooses to use one of these third-party services, using their own API credentials, @Graph may transmit information selected by the user to the corresponding service for analyses and/or processing.
