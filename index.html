Overview

AtGraph is a data visualization, analysis, and statistics application for macOS.

Features

High-performance plotting

Render large datasets smoothly with interactive graphs and charts.

Image analysis for fluorescence microscopy

Open time-series images and plot and measure ROI values.

Scientific file support

Import common electrophysiology and research data formats.

Analysis tools

Process, measure, and display experimental data.

Statistics tools

Apply appropriate parametric or non-parametric tests on data.

macOS native

Built with SwiftUI for a fast and modern Mac experience.

Privacy

AtGraph does not collect, transmit, or store personal information.

All data remain on the user's computer. No data are transmitted to the developer.
