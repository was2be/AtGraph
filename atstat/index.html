Overview

@Stat by @Graph is a native macOS application for statistical analyses of data. Easy, accurate, and elegant statistics without the complexity of a full scientific analysis suite.

Features

Semi-automated statistical analyses

@Stat automatically identifies and applies appropriate statistical tests to help you better understand your data.

Descriptive statistics

Quickly reveal means, medians, standard deviations, and other summary statistics for your data sets.

Focus on effect sizes and confidence intervals

Automatically calculate effect sizes and confidence intervals and generate Estimation Plots of your data.

Rigorous statistical tests

Whether independent samples or repeated measures, @Stat delivers appropriate tests, including corrections for multiple comparisons.

Visualize data in elegant charts

Display data as editable bar charts, scatter plots, estimation plots, or survival curves.

Familiar spreadsheets

Import data from common spreadsheet formats or copy and paste data into a clean, easy-to-use native spreadsheet interface. See every file type.

Export or print results

Easily print or export your charts and statistical results to a variety of image formats, including vector-based SVG.

Compatible with @Graph

@Stat reads and writes native @Graph (.@Graph) charts, spreadsheets, and statistics pages for full inter-app compatibility.

Native for macOS

Built for Apple silicon, providing an intuitive and modern macOS experience.

Files @Stat Opens

Open a file with File › Open, or drop it on @Stat’s Welcome window or any of its windows.
