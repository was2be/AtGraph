@Stat Overview

@Stat (by @Graph) is a macOS app for statistics and charts. It makes 8 chart types (Bar / Dot, Horizontal Bar, Line, Scatter (X,Y), Pie, Box Plot, Estimation Plot and Kaplan-Meier Curve) and shares @Graph's statistics engine: effect sizes with their confidence intervals, then the matching tests. If you are new to @Stat, start with Getting Started.

@Stat and @Graph are alternatives: for recordings, imaging and curve fitting, use @Graph. Both save charts and spreadsheets as .@graph files, and @Stat opens a .@graph chart when it is one of the 8 types @Stat makes.

How Data Moves Between Windows

  • CSV, workbook or pasted table → Spreadsheet → Data to Chart → Statistics tab → a figure with its statistics.
  • Spreadsheet → Data Statistics → Full Statistics window → Send to Data Log or Export Report….
  • A table of text in the Data Log or a Text Editor → select it → Chart Selection… → a chart.
  • Any Bar / Dot, Horizontal Bar or Box Plot chart → Statistics tab › Show Estimation Plot → the same chart as an estimation plot. Click the button again to switch back. A Line chart switches with Estimation Plot under Chart Type, in the Chart tab.

Getting Started walks through these steps once, with the Sample Chart.

Undo, Save and Close

  • Undo and Redo (⌘Z and ⇧⌘Z, or the toolbar buttons) go back up to 50 steps. In a chart window, ⌘Z also undoes changes made in the Chart and Statistics tabs; undo data edits in the Chart Data window.
  • Save (⌘S) and Save As… (⇧⌘S) write a chart or spreadsheet to a .@graph file.
  • A • after a window's title means unsaved changes. Closing the window or quitting asks whether to save them, and Review Changes… goes through each window in turn.

@Stat Keeps Your Data Safe

While you work, @Stat keeps a recovery copy of each chart, spreadsheet and Text Editor window with unsaved changes, and of the Data Log. If your Mac shuts down before you save, @Stat offers to bring those windows back the next time you open it.

  • Reopen brings the windows back as they were, still marked as unsaved. A window that came from a file saves back to it with ⌘S.
  • The Data Log comes back as a Text Editor window titled Recovered Data Log.
  • Don't Reopen moves the copies to the Trash.
  • Recovery copies never change your own files, and they are removed when you save, close the window or quit.

Using VoiceOver

  • Each chart reads as one item that gives its type, axes, and each group's n, center and spread. Press VO-Shift-Return on it to hear the data as an Audio Graph.
  • In a spreadsheet, each column header's Column Actions (and the toolbar's Column Actions button, for the selected cell's column) opens the column's menu: Insert, Rename and Delete Column, and Sort. Each row number's Row Actions opens the row's.

Getting Started

This page takes you through a first session: open a file, make a chart, run a statistic, then save and export. Each part points to the page that covers it in full.

Choosing Sheets and Tables

A workbook, Numbers document, Prism, JSON, SAS transport or NumPy .npz file can hold several sheets or tables, and an FCS file several data sets. @Stat then asks which to open.

  1. Open the file. @Stat lists its sheets or tables with a checkbox each, and each table's size and kind when the file states them. The first is checked.
  2. Check the ones you want, or click Select All (⌘A).
  3. Click Open (its title counts them, such as Open 3 Sheets), or press Return.
  • One table opens in its own Spreadsheet window. Several open as tabs of one window, in the file's order.
  • Double-click a row to open just that one. Space checks or unchecks the highlighted row (move with the arrow keys), and Escape cancels.
  • Select All shows a dash when only some are checked; clicking it then checks them all.
  • Opening many shows a small progress panel; Stop keeps the ones already open. Any that can't be opened (an empty sheet, say) are listed together at the end.

Make a Chart and Run a Statistic

  1. Click Sample Chart in the Welcome window. To use your own data, put it in a spreadsheet (File › New Spreadsheet, ⌥⌘N) with one column for each group and the group names in the first row, then click Data to Chart.
  2. The chart opens with its inspector. Click the Chart tab, then click a type under Chart Type and set the chart's look.
  3. Click the Statistics tab. Under EFFECT SIZE, choose what to Compare, then click Compute Brackets. Each comparison is drawn on the chart as a bracket with its effect size and test. The Sample Chart opens with its brackets already computed, each group against Group 1.
  4. For the full tables, or for correlation, regression and categorical tests, click Open Full Statistics Window, set the analysis up and click Determine Effect.

See Charts › Make a Chart, Statistics on a Chart and Statistics: Overview.

Save and Export

  1. Press ⌘S (File › Save) to save a chart or spreadsheet as a .@graph file, which keeps the data and the figure's look. Text Editor windows and the Data Log save as plain text (see Data Log & Text Editors).
  2. For a figure, click the Export button, the first tool button in the chart window's toolbar, and choose a format (PNG, JPEG, TIFF, GIF, PDF or SVG). To put it on the clipboard instead, right-click the chart and choose Copy as PDF.
  3. For the numbers, click Export… in a Spreadsheet or Chart Data window (File › Export…, ⇧⌘E), choose CSV, TSV or Excel (.xlsx), then click Export… and name the file.
  4. To print the front window, choose File › Print… (⌘P).
  • Export… writes the whole sheet. Values are exported, not formulas. The Excel file keeps numbers as numbers, with the header row in bold and kept in view.
  • With Numbers installed, check Open in Numbers after exporting to open the exported file there too, or click Open in Numbers to open the table there without saving a file.
  • For image sizes, Copy as PDF, statistics reports and printing, see Exporting Results.

Renaming Windows

Double-click the title bar of a Chart, Chart Data, Spreadsheet, Text Editor or Statistics window to rename it, or choose File › Rename… (⌃⌘R). Type the new name and press Return, or Escape to keep the old one. The Data Log keeps its name.

The Data Log and Sessions

  • The Data Log collects the results you send to it. ⌘L (View › Show Data Log) brings it to the front, and pressing ⌘L again while it is in front hides it without losing anything. Window › Data Log and the Welcome window's Open Data Log button bring it forward too.
  • @Stat does not reopen the windows that were open when you quit. Windows open only when you ask for them.

Supported File Formats

@Stat opens every format on this page directly, with no conversion step. The formats are listed in the groups its Welcome window shows, and each entry says what the file opens as and what is read from it.

Open a File

  1. Choose File › Open File… (⌘O), or click Open File… in the Welcome window, and select one or more files. Or drop them onto the Welcome window, the Dock icon or an empty Spreadsheet window.
  2. If the file holds several sheets or tables, @Stat lists them. Check the ones you want and click Open (see Getting Started › Choosing Sheets and Tables).
  3. A table opens in a new Spreadsheet window, ready for Data to Chart. A text file opens in a Text Editor window, and a .@graph file as the chart or spreadsheet it was saved as.

Files @Stat can't open, such as @Graph's recordings, its Graph and Imaging files and its charts of a type @Stat doesn't make, show an alert saying why (for a chart: "@Stat Doesn't Make This Chart"; open it in @Graph).

How numbers, dates and formulas are read

  • Number formats (Excel and Numbers): each number is its stored value, shown as the file formats it (percentages, decimal places, thousands separators, currency signs and scientific notation), with your Mac's decimal and grouping marks. A cell formatted as 45% shows 45% and holds 0.45, which formulas and Copy use; a chart made from it shows 45% or 0.45, as its Show percentages as switch says (see Spreadsheets › Number Formats).
  • Percentages in text: "45%" in a table or file is read as a percentage. A chart shows it as 45% or 0.45, as its Show percentages as switch says (see Charts).
  • Dates and times (Excel): cells formatted as dates or times show as 2026-10-05, 14:30:00 or both, with milliseconds when they have any (14:30:00.250). Elapsed times such as [h]:mm:ss stay numbers, a count of days (36:00:00 is 1.5).
  • Formulas (Excel and Numbers): a formula comes in live when @Stat computes the result the file saved; otherwise the cell keeps the saved value (see Spreadsheets › Formulas).
  • Error values (#N/A, #DIV/0!) show as Excel shows them and count as missing values.

Workspaces

Data Log & Text Editors

The Data Log is a plain-text window that collects the results you send to it. You can also type and paste into it, do arithmetic in it, and send any table in it to a Chart, a Spreadsheet or Statistics. Text Editor windows work the same way but collect nothing: use them for notes and for tables of your own.

Use the Data Log

  1. Choose View › Show Data Log (⌘L) or Window › Data Log, or click Open Data Log in the Welcome window. There is one Data Log, and it keeps its contents while its window is closed.
  2. In the Full Statistics window, click Send to Data Log. The result is added at the end of the log; nothing is overwritten.
  3. To use a table in the log, select its rows, click the blue Text Tools button and choose an action, such as Chart Selection… (⇧⌘H) or Send to Spreadsheet… (see Text Tools, below).
  4. Choose File › Save (⌘S) to keep the log as a text file.
  • ⌘L hides the Data Log when it is the window in front (the menu item then reads Hide Data Log), and brings it forward otherwise. Window › Data Log is checked while the log is on screen.
  • Paste (⌘V) brings text in as plain text. ⇧⌥⌘V pastes it with its formatting.
  • Wrap Lines (toolbar, or View › Wrap Lines; on by default): notes and messages wrap to the window's width, while each row of a logged table stays on one line with its columns lined up. Scroll sideways to read a wide table. Turn it off to keep every line whole.
  • Edit › Find › Find… (⌘F) searches the text; Find and Replace… is ⌥⌘F.
  • File › Save As… (⇧⌘S) saves the log under a new name, and File › Print… (⌘P) prints it.
  • When the log grows past about 5 MB, @Stat offers Save and Clear…; the log is cleared only after the file is saved. When you quit, @Stat asks about unsaved Data Log text.

What Is Logged

  • Results reach the log only when you click Send to Data Log.
  • @Stat itself adds short notes, such as when a chart leaves out part of your data, or how many formulas came in from an Excel or Numbers file.
  • Settings › General › Data Log has "Timestamp each log entry" (off by default), which adds the time to each entry; "Log routine file and window activity" (on), which records routine notes such as exports; and Default font size (13 pt), for new Text Editor windows and for the Data Log the next time it opens.

Text Editors

  • File › New Text Editor (⇧⌘N) opens a separate text window, a new one each time, with the same Text Tools, Find and Math Evaluator as the Data Log.
  • Every line holding a tab is a table row: it stays on one line with its columns lined up, whether it was typed, pasted or opened from a file. Other lines wrap to the window's width.
  • View › Wrap Lines (on by default) is each Text Editor's own: turn it off to keep every line whole. A new Text Editor starts with the last choice made.
  • Save (⌘S) saves the text as a plain-text file (see Getting Started › Opening a File).

Math Evaluator

The Data Log and Text Editors work as a calculator.

  1. Type an expression followed by = (such as 88*3= or "The total is 37*81="). The result appears in blue after the =, and you can keep typing on the same line.
  2. Or type an expression on a line of its own, such as sqrt(144), and press Enter on the numeric keypad. The result appears in blue on the next line. Return just starts a new line.
  • Operators: + − * / % (remainder) and ^ (power), with parentheses. You can paste the signs × · ÷ and −. Use a period for decimals, and write every multiplication: 2*x, not 2x.
  • Functions: sqrt, cbrt, abs, exp, exp2, expm1 (eˣ − 1); ln and log (both the natural log), log10, log2, log1p (ln(1 + x)); sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, asinh, acosh, atanh, with angles in radians; erf, erfc, gamma, lgamma; floor, ceil, round, trunc, sign; and with two values atan2, pow, hypot, min, max, mod and fmod.
  • Constants: pi (or π), tau (2π) and e, written in lowercase.
  • Results: whole numbers below 10^15 show in full; other results show 13 significant digits.
  • Order and rounding: ^ groups from the right (2^3^2 is 512) and binds tighter than a leading minus (−2^2 is −4), where Excel gives 64 and 4. % and mod give the remainder with the sign of the divisor (−7 % 3 is 2); fmod keeps the sign of the first value. round takes halves away from zero (2.5 gives 3).
  • A lone number or a date (2024-05-01) gets no result, so you can type a column of numbers on the keypad. If no result appears, start the expression at the beginning of the line or after words, as in "Total: 37*81=".

Spreadsheets

A spreadsheet holds a table of cells that you type, paste or open from a file, and sends it to a Chart or Statistics. Each column is one category or series, and each row is one replicate.

Enter Data and Make a Chart

  1. Choose File › New Spreadsheet (⌥⌘N), or click New Spreadsheet in the Welcome window. A blank 20 × 20 grid opens, titled Spreadsheet 1, Spreadsheet 2 and so on until you save it.
  2. Type your data, paste it with ⌘V, or drop a data file onto the empty grid.
  3. Double-click each column header and type a name. The names become the category or series names in the chart; unnamed columns get generic names.
  4. Click Data to Chart, Kaplan-Meier or Data Statistics.
  • Data to Chart opens a chart window named after the spreadsheet, such as Spreadsheet 1 Chart. The chart keeps its own copy of the data: later edits in the spreadsheet don't change it. A column name typed over several lines keeps its lines: the chart stacks them under the bar.
  • Kaplan-Meier builds a survival curve from columns in this order: Time, Status (1 = event, 0 = censored), and optionally Group and Stratum (see Charts).
  • Data Statistics opens the Full Statistics window with the table.
  • All three use the whole sheet. Whether rows are the same subject measured repeatedly is set afterward, with Paired / Repeated (see Statistics on a Chart).
  • Opening a CSV, TSV, Excel, Numbers, Stata, Prism, JSON, SAS transport, SPSS, Parquet, Apache Arrow or Feather, NumPy or FCS file fills a new Spreadsheet window with its data (see Supported File Formats). A file dropped onto a spreadsheet that already has data opens in its own window.
  • Export… (also File › Export…, ⇧⌘E) writes the sheet as CSV, TSV or Excel (.xlsx), and can open it in Numbers (see Getting Started).

Edit Cells

  • Double-click a cell to edit it, or select it and start typing to replace its contents. Return commits and moves down; Tab commits and moves right. Option-Return starts a new line in the cell.
  • Shift-click or drag to select a block of cells; Command-click adds or removes one cell. Click a column header or row number to select the whole column or row; Shift-click adds more, and Command-click a row number adds or removes that row.
  • Delete clears the selected cells. Copy (⌘C) copies them as tab-separated text, or the whole table when nothing is selected.
  • Paste (⌘V) pastes tab-separated text, as Excel, Numbers and Prism copy it, at the selected cell, or at the top left when nothing is selected. The grid grows to fit.
  • A table pasted at the first row with its own header row puts the header in the column names. Into an empty spreadsheet, a table always goes at the top left.
  • For comma- or semicolon-separated text, open it as a .csv file, or select it in the Data Log and choose Text Tools › Send to Spreadsheet….
  • Fill: point at a cell that holds something and drag one of the dots on its edges to copy it into the cells you drag over. Edit › Fill Down (⌘D) copies the top row of a selected block into the rest of it, and Fill Right (⌘R) its left column. Formulas move their references ($ parts stay fixed); values are copied as they are, without continuing a series.
  • Transpose Table swaps rows and columns. Clear All, in red at the right of the toolbar, empties every cell.
  • Undo (⌘Z) and Redo (⇧⌘Z) step through up to 50 changes. While you are typing in a cell, ⌘Z undoes the typing first.

Rows, Columns and Sorting

  • Point at a column header or row number and click the caret that appears. The menu has Insert Column Before, Insert Column After, Rename Column… and Delete Column, or Insert Row Above, Insert Row Below and Delete Row.
  • With several rows or columns selected, the menu reads Delete Selected Rows or Delete Selected Columns, and the Insert items add that many at once, such as Insert 3 Columns Before. One Undo brings them all back. Delete is dimmed when it would leave no row or column.
  • The toolbar's Column Actions button opens the same menu for the selected cell's column, so you can reach it from the keyboard.
  • Sort (toolbar, or Sort Ascending and Sort Descending in a column's menu) sorts the rows by the selected column. Whole rows move, the column names stay put, numbers come before text, and blanks go last. If a formula reads another row, @Stat asks before sorting, since the formula would then read different cells.
  • Drag the line between two column headers to make the column on its left wider or narrower, or double-click the line to fit the column to its contents.
  • The menus, Column Actions and column widths work the same way in a chart's Chart Data window.

Formulas

Row 1 is the first row under the column names. Point at a column name to see its letter; the bar under the grid shows the selected cell's address and formula. To compute a new column from the others:

  1. Click the first empty cell beside your data, in row 1.
  2. Type = and the formula, such as =B1*1000 or =AVERAGE(B1:D1), and press Return. The cell shows the result.
  3. Select that cell and the cells below it, then choose Edit › Fill Down (⌘D), or drag the cell's bottom dot down. Each row's formula reads its own row.
  • A formula starts with =, as in Excel or Numbers: =SUM(B2:B20), =AVERAGE(B:B), =B2/$B$1, =IF(C2>0,"up","down"). The cell updates when the cells it uses change. Double-click it to edit the formula.
  • Use $ to keep a row or column fixed when the formula is copied or filled. Copy and Paste move references as Excel does, and inserting or deleting rows and columns keeps them pointing at the same cells. A reference to a deleted cell shows #REF!.
  • Charts, Statistics and exports use the results, and a cell showing an error counts as missing. Formulas are saved with the spreadsheet. Chart data tables hold values only.
  • Text starting with = in an opened text file stays text. To type text that starts with =, begin with an apostrophe ('=).
  • Formulas in Excel (.xlsx, .xls) and Numbers (.numbers) files come in as live formulas when @Stat gets the same result the file saved. Otherwise the cell keeps its saved value. So does a formula that uses a function @Stat doesn't have (such as VLOOKUP, NOW or RAND), refers to another sheet or table, uses a named range, or is an array formula. Window › Data Log lists how many formulas came in live and how many as values, and why.
  • Row numbers are one lower here than in the file, because the file's first row becomes the column names: =A2*32 in Excel is =A1*32 in @Stat.

Functions

Operators: + − * / and ^ (power); % after a number is a percent (50% is 0.5) and between two values the remainder; & joins text; = <> < > <= >= compare. A range is written B2:B20, or B:B for a whole column. Where a range goes, a list of numbers can be typed in braces instead: {2,3,4} is a row and {2;3;4} a column. SUM, AVERAGE and the other summary functions skip blank and text cells in a range, and an error cell makes their result that error; COUNT skips errors too.

  • Totals and averages: SUM, PRODUCT, AVERAGE, MEDIAN, MIN and MAX. MIN and MAX of no numbers are 0, as in Excel.
  • Counting: COUNT (cells holding numbers), COUNTA (cells that aren't empty) and COUNTBLANK(range) (empty cells).
  • Spread: STDEV or STDEV.S and VAR or VAR.S for a sample (n − 1); STDEV.P or STDEVP and VAR.P or VARP for a whole population (n); SEM, the standard error of the mean (SD / √n).
  • Lines and correlation: SLOPE(y range, x range) and INTERCEPT(y range, x range) of the least-squares line, RSQ (r²) and CORREL or PEARSON (Pearson's r). The two ranges must be the same size, or the result is #N/A. Cells are paired by position, and a pair is left out when either cell is blank or text, as in Excel. The x values can be typed as a list: with nine time points in columns C to K, =SLOPE(C2:K2,{1,2,3,4,5,6,7,8,9}) is row 2's change per time point, and the list stays the same when the formula is filled down. For unevenly spaced times, type the times themselves, such as {0,5,15,30,60}.
  • Rounding: ROUND(x, digits); ROUNDUP and ROUNDDOWN (away from and toward zero); TRUNC(x, digits); INT (down to a whole number); CEIL(x) (up to a whole number); CEILING(x, step) and FLOOR(x, step) (up or down to a multiple of step, 1 if left out).
  • Arithmetic: ABS, SIGN, SQRT, CBRT (cube root), POWER(x, y) or POW, HYPOT(x, y) (√(x² + y²)), MOD(x, y) (the remainder, with the sign of y, as in Excel) and FMOD(x, y) (the remainder with the sign of x).
  • Exponentials and logarithms: EXP, EXP2 (2 to the x), EXPM1 (eˣ − 1, accurate for small x), LN, LOG(x) (base 10) or LOG(x, base), LOG10, LOG2 and LOG1P (ln(1 + x), accurate for small x).
  • Trigonometry, in radians: SIN, COS, TAN, ASIN, ACOS, ATAN, ATAN2(x, y) (the angle of the point (x, y), in Excel's order), SINH, COSH, TANH, ASINH, ACOSH, ATANH and PI().
  • Special functions: ERF(x), or ERF(lower, upper) for the integral between two limits; ERFC; GAMMA or TGAMMA; LGAMMA or GAMMALN (the log of the gamma function).
  • Logic: IF(test, then, else), AND, OR, NOT, TRUE(), FALSE() and IFERROR(value, value if error).
  • Checks: ISBLANK, ISNUMBER, ISTEXT and ISERROR, each TRUE or FALSE; NA() gives #N/A, to mark a value as missing.

How Cells Are Read

  • A blank or non-numeric cell ("NA", "–", or a spreadsheet error such as #N/A or #DIV/0!) is a missing value. It is left out of that column's statistics but keeps its row, so in a paired design each row stays one subject.
  • A cell marked with a limit, such as <0.5 or >29, says only that its value lies past that limit. Every analysis treats it as missing, and the data checks, the result and the figure legend say how many there are. Only the mixed model for profiles can fit it instead (Fit values past a limit).
  • Numbers may use a decimal point or a decimal comma: "12,5" is read as 12.5, and a semicolon-separated CSV is split at its semicolons. Currency signs and thousands separators are read too ("$1,234.50" is 1234.5). Excel, Numbers, Stata and Prism files store a decimal point, so your Mac's region setting doesn't affect them.

Number Formats

Numbers keep the format their file gives them: a cell Excel shows as 2.6%, 290,000, 1.50 or $1,234.50 shows the same here, and so does its editor, with your Mac's decimal and grouping marks. A format changes only how the number looks. The cell holds the value the file stored (0.025974… for 2.6%), and formulas, sorting, Copy and Data Statistics use that value.

  • Data to Chart reads a percent cell as the percentage it shows (2.6 for 2.6%). On the chart, Show percentages as (Chart tab) switches between 45% and 0.45.
  • Type or paste a percentage, such as 3% or 12.5%, and the cell holds 0.03 or 0.125 and shows 3% or 12.5%.
  • Edit a formatted cell as it's shown, with or without its unit or parentheses: 1.6 mV, (1,240). Left unchanged, it keeps every digit; 5 typed into a percent cell is 5%. Text that isn't a number, typed over a number, is refused: the cell keeps its value, and a line in the window says why; NA and limits such as <0.5 are entered as typed. To enter other text, start it with an apostrophe ('). Entering text, or clearing the cell, removes its format.
  • Formats move with their cells when you insert or delete rows and columns, sort or transpose. Copy and Paste between spreadsheets, and Fill, carry them too, and Undo restores them. The column names never take a format.
  • Formats are saved with the spreadsheet, and an export to Excel (and Open in Numbers) keeps them, so the workbook looks the same in Excel. CSV and TSV exports hold the plain values. A sheet whose numbers have decimal commas is exported as CSV with semicolons between the cells, as Excel writes CSV in those regions.
  • Print shows the cells as they look.
  • Formats are read from Excel (.xlsx, .xls) and Numbers (.numbers) files: fixed decimals, thousands separators, percentages, scientific notation, currency and other text before or after the number, and separate formats for negative numbers and zero. Dates come in as dates, and any other format (fractions, for example) shows the plain value.

Charts

A chart draws a table of values as a figure, with the data points, error bars and, from its Statistics tab, statistics. Brackets, the Estimation Plot and the mixed model for profiles are on the Statistics on a Chart page.

Make a Chart

  1. Put the data in a Spreadsheet window (File › New Spreadsheet, ⌥⌘N): usually one column per category and one row per replicate, with the column names in the first row.
  2. Click Data to Chart in its toolbar. Or select a table in the Data Log or a Text Editor window and choose Chart Selection… (⇧⌘H) from the Text Tools or File menu.
  3. If the table can be read in more than one way, a "How Should This Table Be Read?" dialog asks.
  4. A Chart window opens, usually as Bar / Dot. To change the type, click another under Chart Type in the inspector's Chart tab.
  5. Style the chart in the Chart tab's Plot Style, Axes & Labels and Range panels (see Chart Settings), and add statistics on the Statistics tab.
  • A first column of row numbers or labels (such as Cell, Subject or ID) labels the rows and is not charted. A chart holds up to 2,000 data points.
  • The chart keeps its own copy of the data: edits in the spreadsheet don't change it. Click Data to Chart again for a new chart, or edit the chart's data in its Chart Data window.
  • File › Duplicate (⇧⌘K) opens an unsaved copy of the front chart. Data Statistics, beside Data to Chart, opens the Full Statistics window on the spreadsheet's data, with no chart needed.

Double-click the chart's title, an axis title or a category label to edit it, and an axis's tick values to set its range. Click a data point to see its value.

Data Layouts

Data Layout, under Chart Type, sets how the table's columns and rows become categories and series. Most tables never need it changed.

Change the Data Layout

  1. In the Chart tab's Data Layout box, choose a layout from the menu. The table is read again at once.
  2. If your groups run down the rows instead of across the columns, check Switch Row/Column.
  3. If the layout can't read the table, a note under the menu says why.

  • One Category (All Values Are Replicates), Each Column Is Its Own Category (its rows are replicates) and Each Column Is Its Own Series (Grouped Bars), where each row is a category.
  • Scatter Plot (X,Y Column Pairs) and Scatter Plot (First Column Is X): see Make a Scatter (X,Y) Chart.
  • One Row per Value (Group Column and Value Column) and Nested (Subcolumns under Each Category): see below.

Long and Nested Tables

When a table looks like one row per value or like a nested table, the Data Layout box offers Read as One Row per Value or Read as Nested; nothing changes until you click it. With either layout, the Chart Data window shows and edits the table as typed.

  • One Row per Value: a column naming each row's group (Control, Treated; or codes 1, 2) and a column of values. Choose them with Groups and Values, under the menu. Other columns, such as the batch, plot or classroom each row came from, stay in the table.
  • Nested: a heading row of categories, each name over its subcolumns (the cells after it left blank), an optional second heading row titling each subcolumn (Batch 1, Batch 2…), then the values. Each category's values are its subcolumns' values together, and Values from the same (Statistics tab) is set to the subcolumns; a title used under two categories is the same source. A table with a heading over every column can't be read as Nested, and the box says so.
  • Where each row came from: when a column's labels repeat beside 2 or more columns of measurements (a Batch column beside one column per treatment), Data Layout asks what the column is: Data (a category of its own) or Names (each row its own category), as it was read, or Where each row came from. The last leaves the column out of the chart and sets Values from the same to it. With Paired / Repeated on, each row also becomes a second level, so the brackets fit (1 | source/row).

Statistics on a Chart › Values from the Same (Clustered Data) says what this does to the statistics.

Work with a Chart

Edit the Data in the Chart Data Window

  1. Click the spreadsheet icon in the chart's toolbar. The Chart Data window opens, titled "Data:" and the chart's name; it closes with the chart.
  2. Edit the cells as in a Spreadsheet window: Undo, Sort, Copy, Paste, Fill and Export… work the same way. The chart, its brackets and a linked Full Statistics window follow each edit, and ⌘S saves the chart.
  3. If the chart came out the wrong way round, click Columns Are Conditions (each column a condition, each row one subject) or Each Column Is a Category (for numbers with no header row). Transpose changes this window's view only.
  • Undo here undoes only the table's edits. In the chart window, ⌘Z takes back changes to the chart's settings and leaves alone a data edit made since.
  • When an edit leaves rows out of the chart, a note in the window says how many and why. When the table can no longer be read as a chart, the chart keeps the data from before.
  • A Kaplan-Meier table's columns are its fields (Time, Status, Group, Stratum), so they can't be inserted, deleted or renamed. To add a Stratum column, paste the whole table with the Paste button.

Make a Scatter (X,Y) Chart

Use a scatter when series were measured at different X values, such as two calibration curves sampled at different concentrations.

  1. Arrange the data as X,Y column pairs (column 1 is the X for column 2, column 3 the X for column 4, and so on), or with the X values in the first column and one Y column per series.
  2. Chart the table. If it doesn't open as a scatter, click Scatter (X,Y) under Chart Type, or set Data Layout to Scatter Plot (X,Y Column Pairs) or Scatter Plot (First Column Is X).
  3. In Plot Style › Scatter (X,Y), set the points' Size and Opacity and each series' color, and check Connect Points to join each series' points.
  4. To fit a line to a series, see Statistics on a Chart › Linear Regression on a Scatter.
  • X,Y column pairs: each series is named after its Y column's header, and the X axis after the first X column's. Pairs may differ in length, and a leftover unpaired column is dropped.
  • First column is X: a table whose first column plainly holds an X opens this way by itself, with Connect Points on.
  • Connect Points joins the points in table order, not sorted by X, so a loop that doubles back keeps its shape. Curved lines smooths the line; where X values double back the curve can swing past the points, and a note says so.
  • Switch X and Y, in the Data Layout box, swaps the axes and their titles. It removes any fit lines, since a fit of Y on X does not describe X on Y.
  • A chart switched to Scatter (X,Y) and back has its original data.

Make a Kaplan-Meier Chart

  4. Choose what is shown, and the tests, in Plot Style › Kaplan-Meier Curve. To cut the curves at a fixed follow-up time, type a Max under Range › Time Axis Range, such as 60 for five years in months.

Plot Style

Data Points is shown for Bar / Dot, Horizontal Bar, Box Plot and Estimation Plot charts; Mean / Bar for Bar / Dot and Horizontal Bar; Error Bars for those two and Line.

Data Points
  • Style: Beeswarm, the default, moves each point sideways just enough to clear the others; where a group is too crowded for its column, the extra points overlap and a note on the chart says how many. Jitter gives a small random sideways spread, Strip puts all points in one line, and None hides them (the default for 0/1 data).
  • Symbol and Point color: see Data Point Symbol. Size is 12 by default.
  • Opacity: strip points, and an Estimation Plot's, start out lighter the more of them share a column. Moving the slider sets the opacity exactly; Automatic Opacity brings the thinning back.
  • Mark possible outliers (off by default) rings in orange each point outside its column's box plot fences.
Mean / Bar
  • Display: Bar, the default; Violin; Mean line; Mean symbol, in the shape chosen under Data Points; or Points only.
  • Bar opacity (50% by default), Bar width (64%) and Bar gap, the space between bars (35%). With 2 or more series, Bar gap is the space between the bars of a group (8%) and Category gap the space between groups.
  • For violins: Median and quartile lines (on by default), Violin width, the widest violin's share of each group's space (90% by default), and Violin opacity.
  • Mean offset, with Mean line or Mean symbol, moves the mean marker sideways, away from the data points.
Error Bars
  • Center: Mean, the default, or Geometric mean, for log-normal data such as concentrations or titers. Copy Geometric Means then copies each group's numbers.
  • The menu under it: None, SD, SEM or CI (see Methods). A new chart starts with Settings › Statistics › New Chart Defaults › Default error bar type (SD unless changed). With Points only there are no means, so no error bars.
  • Color: Chosen color, the default; Same as line or bar; or Same as points. With data points hidden, Same as points follows the line.
  • Show caps (on by default), Cap width, and Bar width, the error bars' line width.
Connection Lines

Checking Paired / Repeated shows this box, turns on Show connection lines and shows bars as mean lines. The lines join each subject's points, the values in one table row; a subject missing a value has its line broken there. Hide data points, Hide mean marker and the lines' opacity, width and color are here too.

Lines and Category Spacing
  • On a Line chart, Lines sets each series' line color, point color and Solid or Dashed line, and the Point size. A missing value breaks the line, and a Line chart draws no brackets.
  • Category gap is the space at each end of the X axis (15% by default; at 0% the first and last points sit on the edges).
  • Curved lines (off by default) joins the points with a smooth curve through every point. It never rises above or falls below its neighbors, so it shows no peak the data don't have.
  • Offset the series slightly (off by default) moves each series a little to the side of the category, so overlapping error bars stay readable.
Box and Wedges
  • Box (Box Plot): the boxes' color, Box opacity and Box width; Notches (off by default); and Copy Box Statistics, which copies each box's n, whiskers, quartiles, median and notch ends as a table. Mean / Bar and Error Bars are hidden; Data Points can draw the values over the boxes.
  • Wedges (Pie): set each wedge's color, rename it (the label, legend and data table all follow), or click ↺ for its default color. Check Explode on a wedge to pull it out of the pie; Axes & Labels › Shape › Explode sets how far, and pulls out every wedge when none is checked.
Kaplan-Meier Curve
  • On by default: Show censor marks (a tick where a subject left the study or was event-free at last follow-up), Show median survival lines, Show log-rank test result, Show confidence band and Show numbers-at-risk table.

  • Weighting: Log-rank, the default; Gehan-Breslow (Wilcoxon); Tarone-Ware; or Fleming-Harrington, with its ρ and γ (0 and 1 at first).

Subjects and Means

For a Repeated Measures by Group chart: Each subject's line, Group means ± error bars (with Join the means across conditions), Offset the groups slightly and Data points show or hide each part. With Each subject's line on, you can set the lines' opacity, width and colors.

Data Point Symbol

Symbol, in the Data Points box, sets the shape of the data points and of the Mean symbol marker: Circle, Square, Diamond or Triangle, each filled or open, or Cross or Plus. Axes & Labels

  • Title, Axis Labels and Tick Values hold each text and its font, size and color. An axis title starts as the table's column header ("Dose (mM)"); a title you typed is never overwritten when the data are read again.
  • Rescale units automatically (Tick Values; on by default): when an axis title ends with a unit in parentheses or brackets, such as "Current (nA)", the axis switches to the prefix that avoids long decimals or long numbers, and the title changes to match: 0.02 nA reads 20 pA. It works for V, A, s, Ω (or ohm), M, mol, g, L, Hz, S, F, W and m; other units are left alone. Only the axis changes: the data, the Range fields and all statistics keep the unit you typed.
  • Axes & Grid: the axis, tick and grid colors and sizes, Dashed grid, Grid lines (5 by default) and Show grid. Show sample size (n) (on by default) writes each group's number of data points by its label.
  • Labels and Shape (Pie): Labels sets what each wedge shows (None, Name, Value, Percent, Name + %, the default, or Name + Value) and the labels' look. Shape sets Inner radius (for a donut), Explode and the wedges' stroke.
  • Appearance: the legend (see Legend); Legend font, also the font of the text a chart adds itself, such as brackets; and Background. If a new background crosses from dark to light or back, @Stat offers to invert the foreground colors.
  • Category names too long to sit side by side are turned 45° (on a Horizontal Bar, wrapped onto two lines) or shortened with an ellipsis (…). In a category label, Option-Return starts a new line.
  • The Add Overlay menu at the top right of the chart adds a movable text label, line or arrow. Drag one to move it, or click it to edit it.

Range

  • Y Axis Range (Value Axis Range on a Horizontal Bar) has a Min and a Max. A Scatter (X,Y) chart has X Axis Range too, and Kaplan-Meier has only Time Axis Range. A pie has no range settings.
  • Type a plain number in the data's units, or add a unit to convert it: on an axis titled in mV, -0.08 V is kept as -80. A unit can be typed only when the axis title names one, as in Vm (mV). Editing the axis title or its unit later never moves the range. Marks beyond a typed range are cut at the axis.
  • The panel flags a Min or Max that isn't a number (the axis treats it as blank) and a Max that isn't above Min. If a bar chart's range leaves out zero, a warning explains that bar lengths then mislead.
  • Automatic range: a chart with filled bars always includes zero, because a bar's length is its value. Other marks show a value as a position, so zero is included only when it is close to the data. Line charts pad around the data.
  • Show percentages as appears for a chart of values written as percentages, such as 45% or a spreadsheet's percent cells (in the Data Layout box for a pie; on a scatter it applies to both axes). 45%, the default, plots them as percentages (45) and adds (%) to the value-axis title once; 0.45 plots them as fractions. Only values written with % change: plain numbers plot as typed, and editing the axis title or its unit never changes the data.

Logarithmic Axes

Logarithmic scale, in the Range panel, draws the value axis, or a scatter's X axis, on a base-10 log scale. It is offered for Bar / Dot, Horizontal Bar, Box Plot, Line and Scatter (X,Y) charts.

  • A log axis can't show zero or negative values, so they are left out, and the Range panel and the Chart Legend say how many. A typed Min or Max must be above zero.
  • Bars are shown as mean symbols, since a bar's length from zero means nothing on a log axis. Your bar setting comes back when you turn the log scale off.
  • Error bars are the mean ± SD, SEM or CI as computed, so they look longer below the mean. One that reaches zero or below is cut at the axis with no cap.
  • Violins are drawn from a density of the log of the values. Box plot quartiles and whiskers come from the values as they are.
  • A scatter's fit line is the least-squares line of the values as they are, so on log axes it curves. For a straight line on log axes, fit the log10 of your values instead.

Legend

Show legend (on by default) and Size, under Axes & Labels › Appearance, apply to every chart's legend. The legend names a chart's series, so a chart with one series has none. Drag a legend to move it; Reset Position puts it back.

  • A Bar / Dot, Horizontal Bar, Line or Box Plot chart of two or more series, and a Pie, also have Layout: Side by Side (the default) or Top to Bottom. A pie moves to make room for its legend.
  • Scatter and Kaplan-Meier charts list their legend one entry per line, at the right of the plot; when you drag it away, the plot widens into the space it leaves. A Kaplan-Meier legend starts inside the plot instead, when a corner the curves leave empty has room for it.

Methods

Error Bars and Centers

  • SD is the standard deviation of a category's values (n − 1 in the denominator). SEM is SD / √n. CI is SEM × the t critical value for n − 1 degrees of freedom, at the confidence level in Settings › Statistics (95% unless changed).
  • In a table of means, an SEM with its n gives the same t-based CI, and an SEM without n a CI from the normal distribution. An SD without n gives no CI, and the Error Bars box says so.
  • The geometric mean is exp of the mean of ln x. Its error bars are × / ÷ the geometric SD factor, exp(SD of ln x), or its confidence interval, the t-interval of ln x back-transformed. They look longer above the mean on a linear axis and symmetric on a log axis. SEM has no geometric counterpart, so it isn't offered.
  • Values at or below zero have no logarithm, so they are left out of a geometric mean, and the panel and the Chart Legend say how many. Geometric mean needs individual values: it isn't available for charts made from means with SD, SEM or n, for 0/1 data, or for violins.
  • Tests and effect sizes still use the values as entered. To compare geometric means, take LN of the values in a spreadsheet and test those: the difference of log means, exp(Δ), is the ratio of geometric means.

Box Plot

  • The box runs from the first to the third quartile, with a line at the median. Quartiles use the (n + 1) rule (Hyndman–Fan type 6), as in GraphPad Prism and Excel's QUARTILE.EXC; R's ggplot2 and NumPy default to type 7. The rule decides which points count as outliers, so state it in your methods: Copy Chart Legend (Statistics tab) writes the sentence.
  • Whiskers reach the most extreme value within 1.5 × IQR (the interquartile range) of the box, Tukey's convention. Points beyond them are drawn as outliers. A category with a single value is drawn as a flat tick.
  • Notches narrow each box at median ± 1.58 × IQR/√n (McGill, Tukey & Larsen 1978), using the IQR of the box drawn. Boxes whose notches don't overlap suggest that their medians differ, at roughly 95% confidence: an informal guide, not a test. With small samples a notch can reach past its box; it is then drawn folded outward, as R's boxplot draws it, and a note says so.

Violins

A violin is a kernel density estimate of each group's values (Gaussian kernel), cut off at the smallest and largest values and scaled to its own widest point, so violins compare in shape. The bandwidth is Silverman's rule, 0.9 × min(SD, IQR/1.34) × n^(−1/5), as in R: because it uses the smaller of the SD and the IQR, an outlier or a second peak does not smooth away the real shape. The solid line marks the median and the dashed lines the quartiles, the same quartiles as Box Plot.

Kaplan-Meier Estimates and Tests

The tests and models give the results of R's survival package (survdiff, coxph, cox.zph), of coxphf for Firth's method and of survminer's pairwise_survdiff.

Curves, bands and medians
  • Each curve drops at each observed event, not at a censoring. The numbers-at-risk table counts the subjects whose time is at or after each tick.
  • The band is a pointwise confidence interval for each curve (Greenwood's variance), at the confidence level in Settings › Statistics. Band scale sets how the band and the median's interval are computed: Log-log stays within 0 to 100% and covers best in small samples (as in SAS and Stata); Log matches R's survfit; Plain is linear.
  • Median survival is the first time the curve drops to 50% or below, or "not reached". Where the curve sits exactly at 50% over an interval, it is that interval's midpoint.
  • The median's confidence interval is read off the band (Brookmeyer & Crowley 1982): from the first event time whose band contains 50% to the last. An upper limit the band never reaches is shown as NR, and a lower limit the band leaves undefined (the curve drops straight to 0) as NE, not estimable.
Tests between groups
  • With 2 or more groups, the log-rank test compares all groups at once. Its p is a large-sample approximation that runs too small with few events, so with fewer than 10 events in all the legend adds "Approximate p".
  • Weighting: Log-rank is the most powerful test when the hazards are proportional. Gehan-Breslow (Gehan 1965; Breslow 1970) and Tarone-Ware (Tarone & Ware 1977) give early times more weight. Fleming-Harrington (Harrington & Fleming 1982) weights each event time by S(t−)^ρ · (1 − S(t−))^γ, for the pooled survival S just before it: ρ = 1, γ = 0 is R's survdiff(rho = 1), and a γ above 0 stresses late differences. Choose the weighting before looking at the curves: trying several and reporting the smallest p inflates false positives.
  • Stratify by the Stratum column compares the groups within each stratum (such as a study site) and combines the results. It also stratifies the Cox model; the curves stay pooled.
  • A group with nobody at risk at any event time, or alone in every risk set it is in (the only group in its stratum, say), is left out of the test, which then has one fewer degree of freedom.
  • Show pairwise tests (Holm), for 3 or more groups, tests every pair with the same weighting and strata and adjusts the p-values by Holm's method (Holm 1979). A pair that can't be tested reads "not testable" and counts as p = 1 in the adjustment.
Hazard ratios
  • With exactly 2 groups, the legend shows a hazard ratio with its confidence interval, labeled with its direction: "HR (B vs A)", where A is the HR reference. It comes from a Cox proportional-hazards model (Cox 1972) with group as its only covariate, Efron's handling of tied times (Efron 1977) and a Wald confidence interval.
  • Show Cox model gives each group's hazard ratio against the reference with its CI, the likelihood-ratio test of all groups at once, and the Schoenfeld-residual test of proportional hazards (Grambsch & Therneau 1994): global, plus one per group with 3 or more groups. A note appears when a proportional-hazards p is below α (0.05 at the default 95% level): the hazard ratio may change over follow-up, so it is an average.
  • When a ratio has no finite estimate (one group has no events, or every event in one group comes after the last subject of the other has left follow-up), the legend shows Firth's penalized estimate instead, labeled "Firth-penalized", with a line saying why. With strata, where Firth's method is not available, the legend says the ratio is not estimable.
  • Firth-penalized Cox fits every hazard ratio by Firth's penalized likelihood (Firth 1993; Heinze & Schemper 2001), with coxphf's defaults. The penalty keeps an estimate finite and reduces small-sample bias, so it also suits small studies. Each ratio has a profile penalized-likelihood CI (not a Wald interval) and a penalized likelihood-ratio p, for up to 11 groups; with more, the legend gives the ratios alone. Tied times use Breslow's method, where the ordinary fit uses Efron's, and the legend says so. The proportional-hazards test is not computed for Firth fits.

  • Trimmed: the highest and lowest 20% of each group are set aside. Yuen's trimmed t (Yuen 1974) does not assume equal variances; its paired form uses the Winsorized covariance between conditions.   • Ranks: for independent groups, Cliff's δ = P(A > B) − P(A < B), how much more often one group's values exceed the other's (Cliff 1993). For paired data, δ is the share of subjects higher in the first condition minus the share higher in the second, leaving out subjects with equal values, with the exact sign test.

Small samples

  • Mann-Whitney and Wilcoxon p-values are exact with fewer than 50 values in each group (or fewer than 50 non-zero paired differences), ties included. Beyond that the table marks the p-value as an approximation.
  • Brunner-Munzel: with 10 or fewer values in a group, p and the CI come from the studentized permutation distribution (Neubert & Brunner 2007; Pauly, Asendorf & Konietschke 2016). It is exact when there are at most 200,000 possible splits of the data, and otherwise uses 10,000 random splits.
  • When every value in one group exceeds every value in the other (δ = ±1), no CI exists and "—" is shown.
  • At very small n a rank-based CI may be unable to reach the requested level. The table then states the level it reaches.
  • H-L shift on independent groups whose spreads differ (Levene's test): a note warns that Mann-Whitney then rejects too often for a difference in medians, and points to Ranks or Trimmed.

Effect Sizes for Means

Means reports a standardized effect size: the mean difference divided by an SD. Two settings in the EFFECT SIZE zone decide which SD, and the test follows the same setting, so an effect size never assumes something its test doesn't.

  • Spreads, for independent groups. May differ (the default) gives Hedges' g* with Welch's tests. Assumed equal gives Hedges' g with Student's t and the classical ANOVA; choose it only when the spreads are known to match, from the design or earlier data. Levene's test is shown beside Spreads for information and never switches it: a Levene p above 0.05 doesn't show that the spreads are equal, and choosing a test from a variance pretest distorts its error rates (Zimmerman 2004).
  • Question, for paired data. Magnitude (the default) gives Hedges' gav: how big was the typical change? Consistency gives Hedges' gz: how consistently did subjects change? The two can differ widely on the same data, and neither is more correct.
  • g or d. Each g is the matching Cohen's d with Hedges' small-sample correction, and is the default. The correction matters most at small n and fades as n grows. Choose d only to match a journal's or a field's convention.
  • Glass's Δ, for a control group. It is offered with Spreads May differ, for two groups (the Control picker beside it chooses which is the control) or for each group vs. a control.

Direction of an Effect

Effect sizes are signed: negative when the first-named group or condition is lower. On a profile with a control group (one you chose, or one named like a control, such as Control, Vehicle or WT), a bracket with the control reads as the other group minus the control, so each treatment's effect has its own sign.

Settings › Statistics › Always show effect sizes as positive restates a negative comparison the other way round: the group names are swapped, and the estimate, its CI, the test statistic and the effect size are given for that order.

  • A one-tailed table of all pairs keeps its tested order, since the row order is the hypothesis, and says so.
  • A chart bracket names no direction, so its effect size and CI are shown as positive.
  • An Estimation Plot stays signed as plotted: the later group minus the earlier.
  • η², ω², Cramér's V and Kendall's W have no sign and are never changed.

Variance-explained effect sizes

  • 1 − 2α is 90% when the confidence level is 95%. At that level the CI excludes zero exactly when the F test is significant at α (Steiger 2004).
  • For a repeated-measures or split-plot within-subjects effect, the interval uses the Greenhouse-Geisser df of the p reported.
  • The interval is for the population's share of variance, the quantity a power analysis plans with (Cohen 1988): the noncentral-F interval for the noncentrality λ, converted by λ/(λ + N). N is the number of observations the effect is estimated from: all values for a between-subjects effect, subjects × conditions for a within-subjects effect, and the subjects for a split-plot's between-subjects effect.
  • R's MBESS package computes the same interval (Kelley 2007). R's effectsize package and JASP convert by λ/(λ + df_error) instead, so their intervals come out higher and wider. The two are not interchangeable.
  • With Welch's ANOVA, η², ω², their CI and Cohen's f still come from the classical ANOVA table, so with very unequal spreads the CI need not agree with Welch's p-value.
  • The sample η² overestimates the population's share at small n, so it can sit near or above the upper end of its interval.

Bootstrap intervals

A bootstrap is used only where no formula fits. Each uses 10,000 resamples and is seeded from the data, so unchanged data give the identical interval. Settings › Statistics › Bootstrap CI method chooses BCa (bias-corrected and accelerated; the default) or Percentile. A plain percentile interval is too narrow at small n, and BCa corrects it for bias and skew (Efron & Tibshirani 1993); choose Percentile only to reproduce a number computed with it.

  • A result row names the method, such as "(BCa bootstrap)", and a chart bracket draws a bootstrap CI in curly braces.
  • Warn on small-sample bootstrap CIs (Settings › Statistics; on, below n = 5, by default) adds a note when a bootstrap CI rests on fewer values per group or pair than that.
  • The Estimation Plot's medians and trimmed means always use the smoothed bootstrap's percentile interval.

Multiple Comparisons (3 or More Groups)

For Means, the Multiple comparisons picker lists only the post-hocs that fit the design, the recommended one first:

  • Independent groups, Spreads May differ: Games-Howell (recommended) or Dunnett's T3 (Dunnett 1980) for all pairs; Dunnett's T3 (recommended) or Games-Howell for vs. Control. Both compare each pair on its own two variances, beside Welch's ANOVA. With small groups (fewer than about 50 each) prefer T3 for all pairs too: Games-Howell can then reject slightly too often.
  • Independent groups, Spreads Assumed equal: Tukey HSD for all pairs or Dunnett for vs. Control, or Holm-Bonferroni, Šidák or Bonferroni, all on the pooled variance, beside the classical F.
  • Paired / Repeated: paired t-tests adjusted by Holm-Bonferroni (recommended), Šidák or Bonferroni. Tukey, Games-Howell and Dunnett assume independent groups and are not offered.
  • Ratio, Trimmed, H-L shift and Ranks: the pairwise p-values are Holm-adjusted over the comparisons tested.

Pairwise CIs are simultaneous, so all the rows can be read together. A mean-difference CI is adjusted as its p-value is. With Holm, and for every effect-size CI, the interval is the Bonferroni one at level 1 − α/m for m comparisons (98.3% for three comparisons at 95%). The exception is Cohen's d in a two-way ANOVA's post-hoc: its CI is per comparison, at the confidence level itself. Holm's procedure has no exactly matching interval, so a Holm p just under the threshold can sit beside a CI that still includes zero.

  • A pair that can't be tested (too few values) is left out, with a note saying so.
  • With paired data and 3 or more conditions, each pairwise comparison uses every subject observed in both of its conditions, and the omnibus test uses the subjects observed in all of them.

One- and Two-Tailed Tests

Tests are two-tailed by default. The Tails picker (Means only) offers one-tailed t-tests and one-tailed Dunnett, Dunnett's T3, Holm, Šidák and Bonferroni comparisons. Tukey HSD and Games-Howell have no one-tailed form, so the picker is hidden for them. A one-tailed choice shows an orange reminder that an effect in the other direction cannot be significant. The CIs become one-sided too (the bound in the tested direction), so each excludes zero exactly when its one-tailed p is significant.

Sphericity (3 or More Repeated Conditions)

Repeated-measures ANOVA and split-plot ANOVA show Mauchly's test and the uncorrected, Greenhouse-Geisser and Huynh-Feldt p-values side by side. The Greenhouse-Geisser p is the result reported, whatever Mauchly's test says: that test has too little power at typical sample sizes to show that sphericity holds, and the correction costs almost nothing when it does (Maxwell & Delaney 2004). In split-plot ANOVA the covariance is pooled within the between-subjects groups. With 2 conditions, or too few complete subjects, the table says that sphericity doesn't apply or can't be tested.

Odds Ratios and Proportions

  • Fisher's exact test reports the conditional maximum-likelihood odds ratio with the exact interval matched to its p-value (Fay 2010), the same CI the chart's brackets show, and the relative risk with a Koopman score interval. When a cell is empty the odds ratio is 0 or ∞, and is printed as such.
  • McNemar's test reports the difference in proportions, Δp = (b − c)/n, with Tango's score interval (Tango 1998), which uses every subject. From the discordant pairs alone it reports the paired odds ratio (b/c) and Cohen's g, with the exact Clopper-Pearson interval. Its p-value is the exact binomial test. The table gives the discordant counts b and c, and notes when fewer than 10 subjects changed, since the odds ratio and Cohen's g then rest on very few of them.
  • The one-sample binomial test reports the observed proportion and its difference from p₀, each with an exact Clopper-Pearson CI, beside the exact two-sided p. For p₀ other than 0.5 the CI and p can disagree just at the threshold; the table then says so, and the p-value decides the test.

Categorical Tests

Choose Categorical under Analysis, then the test in the picker below it; ✦ marks the test the data suggest. Fisher's exact test (2×2), McNemar's test and the one-sample binomial test are described under Compare and Effect Sizes › Odds Ratios and Proportions.

  • Chi-square tests report the smallest expected count. When one is below 1, or more than 20% are below 5 (Cochran 1954), the χ² p-value is unreliable, and the result and the panel suggest Fisher's Exact (r×c), with a Use button.
  • Fisher's Exact (r×c) gives the same table and effect sizes with the exact p-value of the Freeman-Halton extension: the probability, given the row and column totals, of every table no more likely than the one observed. A table too large to enumerate gets a Monte Carlo p-value from 100,000 random tables with the same totals, with its seed shown.
  • Chi-square goodness-of-fit tests the first checked column, one count per category. Under Options, type the expected counts or proportions, separated by commas (or by semicolons when the values use a decimal comma: 0,3; 0,5; 0,2). Left empty, the expected distribution is uniform.
  • Cochran's Q reports an exact permutation p-value beside the χ² one. When few subjects changed (n below 4 or n·k below 24, n counting only the subjects whose responses differ across conditions; Tate & Brown 1970), the exact p is the test's p, the one the result and chart brackets report; otherwise the χ² p is.   • Cochran's Q post hoc: with 3 or more conditions, pairwise McNemar tests follow, for all pairs or for each condition against a control (Comparisons, under Options), as on a chart's brackets.   • McNemar's test and Cochran's Q need 0/1 coding, and the panel says so when the two values are something else.

Linear Mixed Model

Design: Mixed model (repeated measures). For subjects in 2 or more groups, each measured at several conditions: neurons of different subtypes recorded at 10 stimulus intensities, say. A subject missing some conditions is kept, and every value it has counts; repeated-measures and split-plot ANOVA leave out the whole subject. Whether the groups' profiles differ in shape is the Group × Condition interaction.

Fit the model

  1. Lay the table out with one row per subject: a group column, as codes (0, 1, 2…) or labels that repeat (WT, KO), and one column per condition.

Values past a limit

A cell such as <0.5 or >29 says only that its value lies past that limit. With Fit values past a limit checked, each such value counts as lying somewhere past its limit, not as missing: a censored mixed model (the mixed-model form of Tobit regression), fitted by maximum likelihood.

  1. In TEST, check Fit values past a limit.
  2. To count empty cells too, set Empty cells to Below a limit or Above a limit (Missing by default) and give the limit: One number, or a column chosen under Limit. Nested data (Values from the same)

When several subjects come from the same source (a batch, plot, classroom, site, plate, litter or animal), they are not independent. In DATA, choose the column naming each subject's source under Values from the same (None by default; text or numbers). The model then adds a random intercept for each source above the subjects' own: (1 | source) + (1 | subject) in lme4's notation.

  • A column named like a source (Animal, Mouse, Slice, Litter, Subject, Classroom, Plate or Site) whose labels repeat is offered with a link.
  • Effects that differ between sources (the groups, when each source gives one group) are tested against the spread between sources, with degrees of freedom near the number of sources, not the number of subjects.
  • When each group comes from one source of its own, sources can't be told apart from groups, so the model is refused: comparing the groups needs more than one source per group, or sources that hold several groups.
  • The result adds the between-source SD and the number of sources, and notes when that variance is estimated at 0.

One value per row (clustered data)

For a table where each row is one measurement (a sample, a plant, a student, a cell) and rows come from shared sources (batches, plots, classrooms, animals).

  1. Set Design to Mixed model (repeated measures), check only the value column, and choose the group column or None (one group). A table laid out this way is recognized in the Groups or conditions and One sample vs. a value designs, which offer this design with a Use button.
  2. Under Values from the same, choose the column naming each row's source. A second level inside the first (classrooms within each school, slices within each animal) goes under Within that, values from the same.
  3. In TEST, set Spreads: May differ (the default) gives each group its own residual SD, the counterpart of Welch's test; Assumed equal uses one.
  4. Click Determine Effect.
  • The model is value ~ group + (1 | source) in lme4's notation, fitted by REML, with Satterthwaite CIs.
  • The result gives each group's mean and the differences with CIs, and Hedges' g, Cohen's d and Δ (see Method, below); the between- and within-source SDs; the ICC, the share of the variation that lies between sources; n rows and n sources for each group; and the same comparison with the rows treated as independent (Welch's, when spreads may differ), with the ratio of the interval widths.
  • A second level gets its own random intercept within its source, (1 | source/unit) in lme4's notation; the same label in two sources is two units. The result then gives both SDs, the share of the variance at each level, and an ICC for each level.

Nested tables work the same way, row by row down each subcolumn.

The chart

With the Split-plot or Mixed model design, Make Chart opens a repeated-measures chart linked to this window, and the button then reads Show Chart. In a window opened from a chart of the same table, choosing either design turns that chart into the profile instead (Undo in the chart turns it back). Method

  • Fitting: REML, as R's mmrm (Unstructured), lme4 (Random intercept, + slope) and nlme (+ AR(1)) fit it.
  • Degrees of freedom: Satterthwaite's. When the covariance estimates sit at a boundary (a variance component at 0 with a random slope, for example), a note says how they were found. When the fit may not have converged (its likelihood curves the wrong way in some direction), a warning says so, and Unstructured falls back to another structure. When they can't be computed at all, the tests and intervals use the residual df, and the table, the brackets and the chart caption say so.
  • The adjustment: single-step, from the multivariate t distribution of the comparisons (Genz & Bretz 2009), which accounts for how they correlate and so is less conservative than Bonferroni. A re-run gives the same p. When it can't reach its accuracy, or the family has more than 40 comparisons, the adjustment is Bonferroni instead, and the table and the brackets say so.
  • Standardized differences divide each difference by the two groups' SDs of a single value, every level's variance included, such as √(σₐ² + σₑ²) with one value per row (Hedges 2007; Westfall, Kenny & Judd 2014). The two SDs are combined as their root mean square, √((S₁² + S₂²)/2), for groups of different subjects or sources (g* and d*; Delacre et al. 2021), or, with one value per row, as their average, (S₁ + S₂)/2, for groups measured within the same sources (gav and dav; Lakens 2013). Hedges' g adds the exact small-sample correction at the df of that SD, ν = S²/(2·Var S). The CIs are approximate (delta method) and a little wider than the differences' own, so one can reach 0 when p is just below α.

  • The dose-response, kinetics, binding and assay models are described under Statistics on a Chart › Linear Regression on a Scatter.

Show the Comparison on Other Scales

In the Full Statistics window, the DISPLAY zone's "Show the comparison on other scales" (on by default) adds a sensitivity section below a Groups or conditions result: the same comparison on the other Compare scales (Ratio only when every value is above zero). With 2 groups each scale gives its estimate, CI, p-value and test; with 3 or more, its omnibus p (for paired trimmed means, which has no omnibus test, its smallest Holm-adjusted pairwise p). For a Two-way design it adds the same analysis on ranks (Scheirer-Ray-Hare), with H and a chi-square p-value for each factor and the interaction. That needs the same number of values in every A×B cell, and gives too many false positives for the interaction in small samples. A conclusion that holds on only one scale is worth a second look.

Effect Size Brackets

A bracket joins two groups on the chart and shows the effect size of their difference, its confidence interval (CI) and the p-value of the matching test. Brackets are drawn on Bar / Dot, Horizontal Bar and Box Plot charts. A Line chart draws none: change its chart type, or use the Full Statistics window.

Add brackets to a chart

  1. Open the Statistics tab of the chart's inspector.
  2. Turn on Paired / Repeated when each table row is one subject measured in every group.
  3. Read DATA CHARACTERISTICS. When the data's shape suggests another Compare choice, Use applies it (see Data Checks and Suggestions).
  4. Under EFFECT SIZE, choose Compare and, for Means, the effect size (see Compare and Effect Sizes).
  5. With 3 or more groups, under TEST choose All pairwise or vs. Control. The "Will run: …" line names the test.
  6. Click Compute Brackets, at the top of BRACKETS.
  7. Under Display, choose what each bracket shows; under Position, show, hide, nudge or remove brackets.
  • There is no test picker: the test is the one that goes with the Compare choice, so each bracket's p-value and CI answer the same question. Compare stays on Means until you choose another.
  • Brackets stay current: editing the data or changing a setting recomputes those on the chart. If the data can no longer be tested as set up, the brackets are removed and the reason is shown under Compute Brackets.

Settings

The zones above BRACKETS work as in the Full Statistics window (see Statistics: Overview). On a chart:

  • Within category (compare series, not categories), in DATA on a chart with 2 or more series, compares the series within each category, such as WT vs. KO at each condition. Off (the default), the categories are compared using the first series.
  • Mark possible outliers (off by default), in DATA CHARACTERISTICS, rings each flagged point in orange; the checkbox of that name under Plot Style › Data Points is the same setting. A Box Plot marks its own outliers. With Compare set to Trimmed, a cyan ring marks the points the 20% trim sets aside, and a note in the chart's corner explains the ring.
  • Display: the CI checkbox, labeled with its level; Effect size and p-value, each shown or hidden, Above or Below the line; and Header, drawn once above the top bracket: Test name and, with 3 or more groups, Omnibus test (the overall test's statistic, df and p, plus ω² or partial η² for Means). What a bracket shows

  • The effect size with its CI above the line, and p below it. Compare and Effect Sizes › Direction of an Effect explains the sign.

With 3 or more groups the CIs are simultaneous (Bonferroni), like the adjusted p-values. Each CI keeps the confidence level it was computed at.

Adjust p across categories

Adjust p across categories (Holm) appears when brackets are computed once per category: with Within category, and on a chart of two 0/1 series.

  • Off (the default): each category is its own family of comparisons. This suits categories that are separate outcomes or conditions.
  • On: the comparisons of all categories are one family, Holm-adjusted once from each unadjusted p-value, so the chance of any false positive in the whole figure stays at α. For Means with 3 or more series, each pair's t-test takes the post-hoc's place. Use it when the categories together answer one question.
  • The CIs then cover the same family, each at the Bonferroni level 1 − α/M for all M comparisons, since Holm has no exactly matching intervals. Where the CI inverts the test (t-tests, Fisher's and McNemar's exact tests), a CI that excludes the null always has a Holm-adjusted p below α, but a Holm-adjusted p below α can still have a CI that reaches the null.

Estimation Plot

An Estimation Plot shows how large each difference is and how precisely it is estimated: the data, each group's center with its CI, and each difference on its own axis with its CI and sampling distribution. It follows Cumming & Calin-Jageman (2024) and the DABEST plots of Ho et al. (2019).

Make an Estimation Plot

  1. Start from a Bar / Dot, Horizontal Bar or Box Plot chart with one series and at least 2 categories.
  2. In the Statistics tab, set Paired / Repeated, and under EFFECT SIZE choose Compare, which decides what the difference axis shows.
  3. Click Show Estimation Plot, at the foot of the EFFECT SIZE zone. The chart becomes an Estimation Plot, and the button stays highlighted.
  4. With 3 or more groups, choose Differences in the Chart tab's Plot Style panel: each group vs. one group, or All pairwise.
  5. Click Show Estimation Plot again to return to the earlier chart type.
  • Estimation Plot under Chart Type, in the Chart tab, does the same, and is the way to switch a Line chart or a profile.
  • An Estimation Plot compares the categories of one series. With 2 or more series the button is grayed out, and its tooltip says why. A profile is the exception (below).
  • Differences starts at the control chosen for the brackets, else a group named like a control (Control, Vehicle, WT), else the first group. Glass's Δ uses the same control.
  • Plot Style also has Hide data points, Hide mean marker & error bars, Hide sampling distributions and Mean offset, which moves each center and its curve sideways.

How the intervals are found

  • Every CI on the plot, for each center and each difference, is a bootstrap interval from 10,000 resamples, at the Default confidence level in Settings › Statistics. Each curve is the bootstrap sampling distribution of that estimate, drawn from the resamples themselves. Paired data are resampled as whole subjects.
  • Means, Ratio and dominance δ use the plain bootstrap, with the Bootstrap CI method chosen in Settings › Statistics (BCa by default).
  • H-L shift and Trimmed, and the group medians under Ranks, use the smoothed bootstrap (Silverman & Young 1987), with its percentile interval. Each resampled value gets a little Gaussian noise, scaled to keep the sample's variance, because a plain bootstrap of a median from a small sample lands on only a few values.
  • These CIs are the plot's own. Brackets and the Full Statistics window report the CIs that go with their tests, so the two can differ slightly.

Estimation Plot of 0/1 data

When every compared value is 0 or 1, the plot shows proportions instead, after DABEST's proportion plot. In the Statistics tab, a Label choice replaces the data checks and Compare.

  • Upper panel: each group's proportion of 1s as a bar, with its Wilson score CI beside it and the count (successes/n) above it.
  • Lower panel: each difference in proportions (Δp, the risk difference) with Newcombe's hybrid score CI (method 10) or, with Paired / Repeated on, Tango's score CI for paired proportions (Tango 1998), on the subjects with a value in both groups.
  • Label: Δp, or Cohen's h = 2·asin√p₂ − 2·asin√p₁ (Cohen 1988).
  • Score intervals are used because a bootstrap interval is too narrow with few 0/1 values (Brown, Cai & DasGupta 2001; Fagerland et al. 2014, 2015). No sampling distributions are drawn.
  • Brackets on the same data report the odds ratio, a different measure, so their p and CI need not agree with the Δp interval.
  • With paired data, bands between neighboring bars show the fraction of subjects going 1→1, 1→0, 0→1 and 0→0, when every subject has a value in both. Show paired flows, in Plot Style, turns them off.

Estimation Plot with Values from the same

When Values from the same is set (see Values from the Same, below), the plot draws the same linear mixed model as the brackets. A bootstrap would treat values from one source as independent and give intervals that are too narrow.

  • Each center is the group's model-based mean, and each difference the difference in model-based means. Each has its own t-based CI (Satterthwaite df), not adjusted over the comparisons as the brackets' CIs are, and each curve is the t distribution of that estimate (Cumming 2012).

  • A checkbox named after your column (Show each batch's mean, for a Batch column; on by default) draws each source's mean as a larger hollow marker (a SuperPlot; Lord et al. 2020).

Estimation Plot of a profile

For a profile (see Repeated Measures by Group, below), choose Estimation Plot under Chart Type, in the Chart tab. The plot has two panels over the conditions, placed at their values when the column names give them (0, 1, 2, 4, 8 h), and comes from one fit of the mixed model that the brackets use.

  • Lower panel: the differences between the groups at each condition, each with the t distribution of its estimate as a half curve.

Paired / Repeated Measures

Paired / Repeated says that each table row is one subject measured in every group. It stays off until you turn it on, or answer Rows Are Subjects (Repeated Measures) when the app asks how to read a table.

  1. Lay the table out with one row per subject and one column per group or condition. A blank cell is that subject's missing value.
  2. Chart the table, and turn on Paired / Repeated at the top of the Chart tab or the Statistics tab.
  3. Set up and compute the brackets as usual. The "Will run: …" line names the paired test.
  • On the chart, lines connect each subject's points. Brackets and the Full Statistics window run the paired form of each Compare choice (see Compare and Effect Sizes), and the data checks look at the paired differences or, with 3 or more conditions, the within-subject residuals.
  • Values are matched by table row: row r of every column is the same subject. Each comparison uses the subjects with a value in both of its groups; repeated-measures ANOVA's omnibus test uses the subjects with every value.
  • A chart whose values did not come from a table with one row per subject has no row information. Paired brackets and connecting lines are then not drawn, and the panel says why, rather than pairing values by their position in each list. If every group has the same number of values, and you know they list the same subjects in the same order, click Values are listed in subject order to pair them by position.

Values from the Same (Clustered Data)

Use Values from the same when the values aren't independent: samples from one batch, plants from one plot, students in one classroom, cells from one animal. Brackets then come from a linear mixed model with a random intercept for each source, so their intervals count the sources as well as the values.

  1. Lay the table out with one row per value: a column of values, a column naming each value's group and a column naming its source. Or use a Nested table, with each source as a subcolumn under its category.
  2. Chart the table and, in the Chart tab, set Data Layout to One Row per Value or Nested.
  3. In the Statistics tab, under Paired / Repeated, choose the source column for Values from the same. For a Nested table, choose Subcolumns (from the layout). A likely column (named like Batch, Subject, Classroom or Plate) is offered as a link.
  4. If the picker is grayed out, click Compare Means below it: Values from the same is for differences in means.
  5. Under EFFECT SIZE, choose the effect size and Spreads, then click Compute Brackets.
  • The "Will run: …" line names the model, fitted by REML with Satterthwaite df: in lme4's notation, value ~ category + (1 | source). The numbers equal those of the Full Statistics window's Mixed model with one value column (see The Full Statistics Window › Linear Mixed Model).
  • Each bracket shows the effect size with its CI, and the p for the difference in model-based means. With 3 or more categories both are simultaneous over the comparisons (single-step, from the multivariate t).
  • The Chart Legend states the model, the ICC (the share of the variance that lies between sources) and the counts of values and sources. With 3 or more categories, Header › Omnibus test adds the ICC and the counts above the brackets.
  • Values from the same needs a table read as One Row per Value or Nested, and Compare set to Means. It compares the categories of one series, and can't be combined with Within category or 0/1 data; the Statistics tab says why.

The effect sizes (Hedges' g, Cohen's d or Δ), Spreads, a second level inside the first (Within that) and pairs within a source are described under The Full Statistics Window › Linear Mixed Model.

The MIXED MODEL zone

  • Brackets: Each condition (the default) draws a bracket for each pair of groups at each condition. Rate of change draws one per pair, for their difference in slope (below).
  • Trend, Covariance, Values from the same, Fit on a log scale, Fit values past a limit and Spreads set the model, as in the Full Statistics window (see The Full Statistics Window › Linear Mixed Model).
  • Effect size, for Each condition: Hedges' g* (bias-corrected), the default, Cohen's d*, or Δ, the difference in the data's units. On a log scale the brackets show the ratio of the groups' geometric means; with values past a limit they show Δ, and p reads p ≈.

What each bracket shows

  • A bracket joins two groups at one condition. It shows the effect size of the difference in their model-based means, with a simultaneous CI and a p adjusted over all conditions and pairs (single-step, from the multivariate t; Bonferroni above 40 comparisons).
  • The difference is the first group minus the second; a pair with a control group reads as the other group minus the control (see Compare and Effect Sizes › Direction of an Effect).
  • Δ's CI excludes 0 exactly when p is below α. g* and d* divide the difference by the root mean square of the two groups' SDs of a single value at that condition; their CIs are approximate and a little wider.
  • The bracket list names each comparison in full ("Hit 8: Subtype 0 vs. Subtype 2") and gives its df beside p: Satterthwaite's, the residual df where those can't be computed (the test name then says so), or subjects − groups with values past a limit. With several subjects per source, they lie nearer the number of sources than of subjects.
  • A condition where every observed value is the same, such as a normalization baseline, is left out of the model and gets no bracket.
  • A bracket's ends are spread across its condition, and brackets at neighboring conditions alternate in height, so their labels stay apart. They are drawn in the SVG, PDF and PNG exports.

Header (BRACKETS › Display) has two more checkboxes on a profile:

  • Counts (on by default) adds the subjects (rows) the model used and, with Values from the same, their sources, in all and per group, as in "n = 60 subjects from 17 batches". It names the groups that share sources, whose comparison is then partly within sources.
  • Rate of change (difference in slope), off by default and offered with Each condition, adds each pair's difference in slope, with its simultaneous CI and adjusted p.

On a Scatter (X,Y) chart, the Statistics tab fits a straight line to each series by ordinary least squares, with Pearson correlation. Series are never pooled, and each line is drawn in its series' color.

Fit a regression line

  1. Open the Statistics tab of a Scatter (X,Y) chart.
  2. Click Linear Regression under a series' name. The line appears dashed, as a preview, with its numbers below.
  3. Click Keep Fit to make the line solid, or Remove to discard it. A kept fit has a Remove Fit button.

Band and options

  • Show band around the fit (off by default) shades a band around every fit line. Confidence band (mean response), the default, is where the true line lies. Prediction band (new observations) is where a new single point would fall, so it is wider. Level is 95% by default (50 to 99.99%).

  • Standardized slope (β) adds the beta weight, B × SD(X) / SD(Y), which with one X equals Pearson r.

  • Residual diagnostics adds a Residual Diagnostics… button to each fit, with the number of rows flagged. qPCR Relative Expression (ΔΔCt)One row per sample: a Group column and the target and reference genes' Ct. ΔCt = Ct(target) − Ct(reference); a group's ΔΔCt is its mean ΔCt minus the control's, and its fold change is 2^−ΔΔCt (Livak & Schmittgen 2001), or Pfaffl's ratio with the genes' efficiencies (Pfaffl 2001). Each group is compared with the control by Welch's t on ΔCt, Holm-adjusted, and the CI is converted to fold change.
  • The curve models are fitted by nonlinear least squares and report each parameter's SE and CI and R² (and AICc, for the unweighted Michaelis–Menten, inhibition and binding fits).
  • Constraints: the dose-response fit can hold Bottom, Top or Hill slope at a value you type (such as Bottom = 0 and Top = 100 for percent data), and the competition fit Bottom and Top. A fixed parameter has no SE or CI, and its degree of freedom goes back to the residuals.
  • Weighting: the dose-response, kinetics, binding and standard-curve fits can be weighted by 1/Y² or 1/Y. The weights come from the fitted curve, re-estimated until they settle (iteratively reweighted least squares; Carroll & Ruppert 1988); R², SEs, CIs and tests then use the weighted sum of squares. A program that takes them from each point's own response, as R's nls(weights = 1/y²) does, gives slightly different numbers.
  • Replicates test for lack of fit: offered for the dose-response, kinetics and binding fits when some dose or concentration is repeated.
  • Compare, for dose-response, fits 2 or more data sets (each checked column against X, or checked X,Y column pairs) and asks whether one curve fits all, or whether LogEC50, Bottom, Top or Hill slope differs. It gives each data set's LogEC50 difference from the first, with its CI and EC50 ratio, then the extra sum-of-squares F test and, if checked, AICc.

Exporting Results

A chart, table or statistics report leaves @Stat as an image, a data file, a copy on the clipboard or a printed page. This page gives the steps for each, then the options.

Export an Image of a Chart

  1. Click the Export button, the first tool button in the chart window's toolbar, or choose File › Export… (⇧⌘E). The Export Chart panel opens.
  2. Choose the Format: PNG, JPEG, TIFF, GIF, PDF or SVG (see Image Formats, below).
  3. Set the size: type the Width and Height in pt, in, cm or mm, or choose a journal's column width from Journal width.
  4. For PNG, JPEG, TIFF or GIF, choose the Resolution. The panel shows the output in pixels.
  5. To leave the background out, turn on Transparent background.
  6. Click Export…, then name the file.
  • The panel starts from the format, size, resolution and background set in Settings › Export (PNG, 1200 × 800 pt, 144 dpi and not transparent unless you changed them).
  • The file shows the figure as it was when you clicked Export…, even if you change it meanwhile.
  • If an export takes more than a moment, a progress indicator appears. Click Cancel to stop it; no file is written.

Copy as PDF

  1. Right-click the chart and choose Copy as PDF.
  2. Paste into Keynote, Pages, Word or any app that accepts PDF. The copy is a vector PDF, with an image alongside for apps that paste only images.
  • A chart is copied as PDF, PNG and TIFF, at the size and resolution set in Settings › Export.
  • Drag (the hand beside the Export button) does the same without the clipboard: drag the chart into Keynote, Pages, Word, Mail or the Finder.

Export a Table

  1. In a Spreadsheet window, or a chart's Chart Data window, click Export…, or choose File › Export… (⇧⌘E).
  2. In the Export Spreadsheet panel, choose the Format: CSV, TSV or Excel (.xlsx).
  3. Click Export…, then name the file.
  • Values are exported, not formulas. For what each format keeps, and for Open in Numbers, see Getting Started › Save and Export and Spreadsheets › Number Formats.
  • A sheet whose numbers have decimal commas is written as CSV with semicolons between the cells, as Excel writes CSV in those regions: in R, read it with read.csv2; in pandas, with sep=";" and decimal=",".
  • The spreadsheet grid has no image export; to put a table on paper or in a PDF, print it.

Save a Statistics Report

  1. Run the analysis in the Full Statistics window (see The Full Statistics Window › Run an Analysis).
  2. Click Export Report….
  3. Choose Text or PDF from Format, then name the file.
  • Send to Data Log adds the same report to the Data Log instead.
  • After a regression, Export Plots saves the four residual plots as a PDF or PNG.

Print

  1. Bring the window to print to the front: a chart, a spreadsheet or a chart's data table, a Full Statistics window, a Text Editor, the Data Log or this guide.
  2. To set the paper size, orientation and scale, choose File › Page Setup… (⇧⌘P). The window keeps them until it closes.
  3. Choose File › Print… (⌘P). It is dimmed when the front window has nothing to print.
  4. In the print dialog, turn on Print header and footer to add the title, date and page numbers, or Fit to page width to shrink a wide table to fit.
